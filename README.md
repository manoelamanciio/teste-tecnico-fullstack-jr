# Mural de Enquetes ao Vivo

Projeto desenvolvido para o teste tecnico de Desenvolvedor(a) Full Stack Junior da FantasyDraft.

## Objetivo

Permitir a criacao de enquetes, o registro de votos e a atualizacao dos resultados em tempo real para todas as pessoas que estiverem visualizando a enquete.

## Stack prevista

- Laravel 11 e PHP 8.3
- PostgreSQL
- React 18
- Node.js e WebSocket com a biblioteca `ws`

## Status

Projeto em construcao.

As instrucoes completas de instalacao, as decisoes tecnicas, o tempo de desenvolvimento e as dificuldades encontradas serao documentados conforme a implementacao evoluir.
